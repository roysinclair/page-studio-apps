**v0.3.0** introduces **Page Orbit**, Page Aura's sister app for Anthropic **Managed Agents**. It's a preview.

## New: Page Orbit

Build, run and fix agents that work in Anthropic's cloud, with your own API key:

- **Agents with versions:** edit in a form or as JSON. Every save is a new version you can compare and roll back. If someone else saved first, you're warned instead of overwriting their work.
- **Talk to an agent live:** messages, tool calls and results as they happen. Approve or deny tool calls, answer custom tools, stop it, attach files, and set an outcome with a rubric for a grader to check.
- **Inspect everything:** a timeline of every event with model request times, tokens and cost; usage and spending caps; sub-agent threads; output files.
- **Diagnose:** a model reads the session and the agent's setup, explains what went wrong with event references, and proposes fixes you apply as a new version.
- **Environments, vaults** (write-only secrets, OAuth test), **schedules** (cron in your time zone, run now, run history), **memory stores** (edit, history, redact, and Dreams in research preview) and **skills** (upload and version).
- **Per session:** a different model or instructions, files to work on, a goal to meet, instructions added mid-session, tool changes, and live helper threads you can stop one by one.
- **Desktop only, with a browser demo:** Anthropic doesn't let web pages call the Managed Agents API, so Page Orbit runs as a desktop app. In a browser, `page-orbit.html?demo` lets anyone explore it with a sample workspace.

## New: a home for both apps
