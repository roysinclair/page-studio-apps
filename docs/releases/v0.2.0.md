Page Aura **v0.2.0**: everything from the roadmap, plus a tighter security story.

## New in both versions

- **Edit and branch:** edit any message you sent and resend from there, or branch the conversation into a new chat and keep the original. Branch from any reply too.
- **Economy research:** Haiku does the web searching and reading at its low price, then hands a sourced summary to your chosen model.
- **Standing notes:** your own notes (location, projects, style) sent with every chat.
- **Sync folder:** keep chats, memories and notes in a folder in iCloud Drive, Dropbox, OneDrive or Google Drive (Chrome/Edge or the desktop app).
- **No third-party code at runtime:** marked, DOMPurify and highlight.js are now embedded and fingerprint-checked, like the Anthropic SDK. This also removes the developer-tools message about a blocked `.map` file.

## New in the desktop app

- **Apps on this computer:** local MCP servers with per-use approval, and **Import from Claude Desktop**. Environment variables are kept in your keychain.
- **Global shortcut:** Ctrl/⌘ + Shift + Space brings Page Aura to the front from anywhere.
- **Notifications** when a reply finishes while Page Aura is in the background.
- **Automatic updates:** optional and signed; see `docs/updates.md`.

## Downloads

| | |
|---|---|
| Standalone | `page-aura.html` |
| Windows | `.msi` or `-setup.exe` |

The installers are unsigned. The [README](https://github.com/roysinclair/page-studio-apps#get-the-desktop-app) shows how to open them, or how to build the app yourself with no warnings. Check downloads against the attached `SHA256SUMS` files.
