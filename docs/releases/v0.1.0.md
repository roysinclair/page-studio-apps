The first release of **Page Aura**: a secure, bring-your-own-key chat app for Anthropic's Claude models. It comes in two forms.

## A. Standalone: `page-aura.html`

One file, nothing to install. Download it, double-click it, and paste your API key. It works in any modern browser (Chrome or Edge recommended).

## B. Desktop app: Windows, macOS, Linux

The same interface as a native app, with your API key in the **system keychain** (the interface never sees it), chats in a real database, and native project folders.

| System | Download |
|---|---|
| Windows | `Page.Aura_0.1.0_x64_en-US.msi` or `Page.Aura_0.1.0_x64-setup.exe` |
| macOS (Apple silicon + Intel) | `Page.Aura_0.1.0_universal.dmg` |
| Linux | `.deb`, `.rpm` or `.AppImage` |

These builds are **unsigned** (Page Aura is free, and signing costs money every year), so you'll see a one-time warning. The [README](https://github.com/roysinclair/page-studio-apps#get-the-desktop-app) shows how to get past it, or how to build the app yourself with no warning at all. Check your download against the `SHA256SUMS` files attached below.

## What's inside

- Up to 4 chats side by side, plus pop-out windows; model and effort chosen per chat
- Photos, PDFs, long pastes and data files
- Optional read-only context from your project folders, including Claude Code memory
- Web search with citations; code and file creation (Word, Excel, PowerPoint, PDF); memory; connected apps (MCP)
- Estimated cost for every reply, plus a balance gauge
- A strict security policy, embedded and fingerprinted code, secret filtering, optional passphrase encryption (standalone) and the system keychain (desktop)
